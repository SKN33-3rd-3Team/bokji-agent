# RunPod 60문장 우선 비교

사용자 선택에 따라 이번 RunPod 실행은 300문장 중 60문장을 먼저 비교한다. 원래 300문장과 이전 결과는 보존한다.

- 원래 100상황 중 20상황을 고르고, 각 상황의 세 표현을 모두 사용한다.
- 일반 15, 정보 부족 12, 경계 조건 12, 질문 대상 구분 9, 근거 없음 6, 잘못된 전제·모순·조작 요구 6문장이다.
- 말투 10종은 각각 6문장이다. 정책 8개를 모두 포함하지만 정책별 문장 수는 같지 않다.
- 질문 이해(N1) 점수 대상은 모델당 48문장이다. 나머지에서도 개인 조건을 지어내는지 확인한다.
- 질문 선택에는 모델 답변을 사용하지 않았다. seed 60으로 말투별 두 상황을 추출해 범주 비율과 정책 범위를 만족한 첫 후보(199번째)를 채택했다. 상세 목록과 해시는 selection.json에 있다.
- 세 모델의 질문, 순서, 정책 원문, 서비스 코드, 출력 한도 1024, 문맥 8192, temperature 0, thinking 비활성화는 동일하다. 모델별 같은 토큰 수가 같은 글자 수를 뜻하지는 않는다.
- 세 모델 모두 Q4_K_M 양자화이다. A.X는 Ghiwook의 공개 변환본이다.
- 추론은 RunPod RTX A5000에서 수행한다. num_gpu=99이며 사전 실행에서 세 모델의 전체 계층 GPU 적재를 확인했다. CPU 비교는 수행하지 않는다.
- 정책 원문을 직접 제공한 질문 이해·상세 답변 시험이다. 검색을 포함한 전체 서비스 시험이나 최신 정책 검증은 아니다.
- 먼저 실행한 RunPod A.X 41문장은 이번 결과에 합산하지 않는다. 사용자 범위 변경으로 연결을 끊은 42번째 시도는 의도적 중단이며 모델 오류로 집계하지 않는다.
- 60문장은 20상황의 표현 변형이다. 서로 독립적인 실제 사용자 질문 60개 또는 전체 서비스 성능으로 해석하지 않는다.
- 답변은 모델명을 가린 별도 AI 검토로 평가한다. 사람 전문가 평가가 아니다.
