# LLM 모델 비교 실험 — 파인튜닝 없이 형식/내용 검증 가능한가

## 배경

"결과물 형식을 일정하게 만들고, 내용이 원문과 일치하는지 확인" 요청을 받아서,
파인튜닝 대신 아래 두 방식으로 되는지 실험함:

1. **형식 일정하게**: `response_format`(JSON 스키마 강제)
2. **내용 일치 확인**: 생성 후 별도로 원문과 대조하는 검증 단계(LLM-as-judge)

## 실행 환경

- RunPod A40 GPU, vLLM으로 모델 로컬 서빙
- 비교 모델 3개(팀 후보 순위 1/2/7위):
  1. `skt/A.X-4.0-Light`
  2. `Qwen/Qwen3.5-9B`
  3. `Bllossom/llama-3.2-Korean-Bllossom-3B`

```bash
vllm serve <model> --max-model-len 16384 --port 8000
python3 test_structured.py
python3 test_verify_negative.py
```

## 결과 (정책 1건 — "영유아보육료 지원" 기준)

| 항목 | skt/A.X-4.0-Light | Qwen3.5-9B | Bllossom-3B |
|---|---|---|---|
| 스키마 형식 준수 | ✅ | ✅ | ✅ |
| 내용 품질 | ✅ 나이·금액·조건 다 담음 | ⚠️ 공허한 문장("정리해 드립니다") | ⚠️ 과도하게 축약(나이·조건 누락) |
| 배지 판정 일관성 | 확인_필요 | 확인_필요 | 자격_충족 (다른 두 모델과 다르게 판정) |
| 검증 정확도 (조작 2개 중) | ✅ 2/2 (금액+소득조건 둘 다 탐지) | ⚠️ 1/2 (금액만 탐지) | ⚠️ 1/2 (금액만, 근거 서술도 부자연스러움) |

## 결론

- **파인튜닝 없이 `response_format` + 별도 검증 호출만으로 두 목적 다 달성 가능함이 확인됨.**
- 3개 모델 다 스키마 형식은 지켰지만, 실제 내용 품질/검증 정확도는 skt/A.X-4.0-Light가 뚜렷하게 앞섬 — 원래 팀 순위표의 1위 판단과 일치.
- **주의**: 정책 1건만 테스트한 결과라 표본이 작음. 결론을 확정하려면 `data/processed/subsidy_documents.jsonl`에서 정책 5~10건을 뽑아 반복 검증하는 게 필요함.
